=== [Unreleased]

==== Added

* Repository minted from `hyperpolymath/rsr-template-repo` via
  `just repo-init julia-library` (2026-09-18); clade `dx` (Developer
  Ecosystem, secondary `pt`), lineage `monorepo`, preset `julia-library`.
* `PROJECT_BRIEF.md` — the canonical Marid product/engineering contract
  (§1–§9), transcribed from the owner's program brief.
* `AGENTS.md` — repository instructions for coding agents, plus the
  Marid-on-RSR file-mapping notes.
* `THIRD_PARTY_NOTICES.md` and `REUSE.toml` (starter license mapping;
  Gate 2 owns the full mapping).
* Monorepo skeleton: `packages/` (Marid core + five integrations), `web/`
  (client, React, Vue, elements), `contracts/`, `fixtures/`,
  `examples/relationship_explorer/`, `test/interop/` — READMEs only, no
  implementation (Gate 0 not yet started).
* `docs/marid-architecture.adoc`, `docs/marid-compatibility.adoc`,
  `docs/marid-roadmap.adoc` (Gate 0 stubs), `docs/audits/`,
  `docs/adr/`, and `docs/agent-launch.adoc` (Gate 0 kickoff and
  bounded-task prompts).

==== Changed

* Framework charter integrated: `docs/MARID-FRAMEWORK.adoc` transcribes
  the owner's charter (mission, principles, package graph, architecture,
  protocol matrix, frontend/storage stories, licensing, non-goals, gated
  roadmap); `docs/FRAMEWORK-ALIGNMENT.adoc` verifies the Gate 0 base
  against it; `PROJECT_BRIEF.md` §1–§3, §5, §7–§9 reconciled
  (amendment 2026-09-19).
* Package graph replaced: the brief's original six (`Marid`,
  `MaridArango`, `MaridGRPC`, `MaridGraphQL`, `MaridCapnProto`,
  `MaridBebop`) superseded by the charter's thirteen (`MaridIR`,
  `MaridCodec`, `MaridOpenAPI`, `MaridRPC`, `MaridGraphQL`,
  `MaridTransport`, `MaridCore`, `ArangoDB`, `MaridStorage`,
  `MaridControl`, `MaridLive`, `MaridCRDT`, `MaridRaft`); stubs only,
  no implementation. Supersession map in the alignment doc.
* Browser language is AffineScript (JaffaScript face, `.affine`
  sources → typed WebAssembly via `@hyperpolymath/affinescript`);
  TypeScript ejected from `ANCHOR.a2ml` (now forbidden), the brief,
  `web/` stubs, quickstart, and agent rules, per estate ruling
  (`LANGUAGE-POLICY.adoc` §1.2, 2026-08-25).
* Runtime migrated to Bun: `node`, `npm`, `yarn`, `pnpm`, and `deno`
  ejected from `mise.toml` (deno per owner ruling 2026-08-26);
  `contracts/` reconciled IR-first; reference-app frontends are
  AffineScript, React, Vue.

==== Removed

* `packages/MaridGRPC/`, `packages/MaridCapnProto/`,
  `packages/MaridBebop/` stubs (gRPC is Phase 8 transport work;
  Cap'n Proto/Bebop message support becomes `MaridCodec` extensions).

==== Fixed

* Regenerated `docs/architecture/REPOSITORY-MAP.adoc` after staging: the
  generator reads tracked files, so a map generated pre-staging omits new
  paths and CI reports it stale.
* `scripts/gen-repo-map.sh`: quote-safe annotation trim. The `| xargs`
  trim interpreted quotes, so an annotation containing an apostrophe
  ("Cap'n Proto") rendered empty; `sed` trims without interpreting.
* `.machine_readable/rsr-profile.a2ml`: added the `[canon]` binding
  (2.0.4, verified against live `canon.lock`). `just repo-init` records
  the canon only in `PROVENANCE.a2ml`, but Canon lockstep reads the
  profile, so minted repos fail lockstep without this block.
* `.github/workflows/main-estate-audit.yml`: repinned cicd-suite
  `f9e173a` → `222b1d9` (main). PR#17 merged 2026-09-17 and the squash
  orphaned its head commit (NOT-ANCESTOR), failing this call and the
  governance action-pin check. Per the pin note's own instruction.
* `.github/workflows/pages.yml`: build timeout 20 → 60 min. The cold
  cabal build (casket-ssg + pandoc) exceeds 20 min and a cancelled job
  saves no cache, so the gate could never go green; warm runs take
  minutes once the first cold build completes.
