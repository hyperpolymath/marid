[#gaps]
== Gaps (open, owned, not silent)

. *DCO sign-off gate.* Charter principle 11 requires CI to fail unsigned
  commits. No gate is wired. Proposed: a commit-message sign-off check
  on pull requests. Needs owner approval before landing (new gate).
. *Dependency review gate.* Same principle; no `dependency-review`
  workflow exists. Proposed with the first manifest (`Project.toml` /
  `package.json`) that introduces dependencies — wiring it now would
  guard nothing.
. *Documenter.jl doc builds.* Arrive with the first Julia code; nothing
  to build at Gate 0.
. *Pages cold build.* Orthogonal estate/tooling item: the 60-minute
  fix is landed; the outcome postdates the last affirmation.
