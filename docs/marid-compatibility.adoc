== Protocol Boundaries & Transport Selection

1. **gRPC Protocol Scope**:
   - **Phase 1–7 Scope**: Native gRPC is deferred. Standard RPC interactions use `MaridRPC` (JSON-RPC 2.0 / MCP over HTTP/SSE).
   - **Phase 8 Scope**: Unary RPC and Server Streaming over HTTP/2 using `libnghttp2` FFI. Client-streaming and Bidirectional streaming are strictly gated on HTTP/2 flow-control validation.
   - **Browser-facing gRPC**: Must use gRPC-Web or Connect protocol gateway. Native gRPC over raw HTTP/2 is not supported directly in web browsers.
2. **GraphQL Subscriptions**:
   - Transport is decoupled from schema: subscriptions operate over Server-Sent Events (SSE) as primary, with WebSocket upgrades for bidirectional feeds.
3. **Cap'n Proto & Bebop Boundaries**:
   - Both are message serialization codecs within `MaridCodec`. Neither is treated as a replacement for standard network RPC protocols.

== Cross-Protocol Type Translation Contract

To prevent silent data corruption or precision loss across Julia, JavaScript/AffineScript, GraphQL, and binary protocols, all adapters adhere to these conversion rules:

[cols="1,1,1,1,2",options="header"]
|===
| Logical Type | Julia Type | JSON / GraphQL | Binary (Bebop/Capnp) | Translation & Overflow Rule

| **64-bit Signed Int**
| `Int64`
| String or `BigInt` in JSON; `String` in GraphQL
| `int64`
| Integers exceeding $2^{53} - 1$ must serialize as strings in JSON to prevent JavaScript precision truncation.

| **64-bit Unsigned Int**
| `UInt64`
| String in JSON; `String` in GraphQL
| `uint64`
| Serialized as base-10 strings in browser-facing endpoints.

| **Timestamp**
| `Dates.DateTime`
| ISO 8601 UTC String (`YYYY-MM-DDTHH:MM:SS.sssZ`)
| `int64` (epoch millis or nanos)
| Millisecond precision standard; always normalized to UTC.

| **Binary Data**
| `Vector{UInt8}`
| Base64-encoded string
| `byte[]` / `Data`
| RFC 4648 Base64 encoding for text transports.

| **Null vs. Omitted**
| `Union{Nothing, T}` vs. `Missing`
| `null` vs. key absent
| Optional field presence tag
| `Nothing` maps to explicit `null`; `Missing` / absent field indicates omitted value.

| **Decimal / Currency**
| `FixedPoint` or `String`
| String
| Custom struct
| Floating-point types (`Float64`) are forbidden for monetary or exact scientific values.
|===
