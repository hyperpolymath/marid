== Overview

This guide covers packaging, deploying, and maintaining marid for
distribution on your platform.

== Runtime Dependencies

Julia General registry via Project.toml [deps] with [compat] closure

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/marid.git
cd marid
just build-release
----

Output: `src/`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t marid .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/marid/`
| Data files, assets

| `$PREFIX/share/doc/marid/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/marid/config.toml`

Fallback: `$HOME/.config/marid/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update marid`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/marid-instance1 --config=/etc/marid/instance1.toml
just install --prefix=/opt/marid-instance2 --config=/etc/marid/instance2.toml
----

Each instance has isolated config, data, and logs.
