== Executive findings

. The repo has all thirteen charter package directories and real prototype source.
  The indexed “no implementation exists” summary is stale. The converse assertion
  in `gate5-release-review.adoc` that all gates are complete and production-ready
  is also unsupported by the present code and tests.
. There are *zero open issues, zero open PRs and zero GitHub releases* at inspection.
  The all-state issues endpoint also returned an empty list. Outstanding engineering
  work is therefore an inferred backlog, not a set of existing numbered issues.
. Unit tests are green but several “integration” tests run only in memory.
  The Arango client itself is a mock; the storage adapter silently delegates to
  memory. Transport has no HTTP listener; GraphQL execution is a stub; binary
  export endpoints contain placeholder strings.
. The requested emitter/CLI seam is now implemented and evaluated against the
  *actual native gateway policy pipeline*. The Compose topology is documented
  and structurally checked, but no end-to-end deployment is claimed.
. A native gateway security limitation prevents strict route allowlisting:
  nonempty global verbs are mandatory and remain public fallback permissions.
  The API/CLI require explicit opt-in instead of silently exposing GET.
. Next: reconcile evidence/CI, prove IR/Codec/Core on a real HTTP path, correct
  upstream gateway semantics, implement real persistence, then prove independent
  adapters and real browsers. Defer registration, polyrepo extraction and own Raft.

== Full product scope and repository map

The charter defines a Julia-first, clean-room framework with one service IR,
independent protocol bindings, a local routing data plane, optional control plane,
pluggable persistence, HTML-first support and framework-independent browser access.
It explicitly excludes Genie API cloning, Cap'n Proto RPC, Julia SSR/RSC,
hand-rolled crypto, a Julia DBMS and premature owned Raft.

[cols="1,2,3",options="header"]
|===
| Area | Intended scope | Observed implementation / missing acceptance
| MaridIR | Descriptors, TypeRefs, annotations, validation; no dependencies
| Data model, `to_dict`, basic name/signature collisions and proto text emitter.
`from_dict` is exported but not implemented; field-reference validation incomplete.
This patch adds tested native Verb Governance Spec generation without dependencies.
| MaridCodec | Negotiation, JSON3, optional binary codecs
| Negotiation returns first matching media type without respecting q-values.
Encoding uses Julia `string(obj)`, not JSON. No JSON3 or native codec extensions.
| MaridOpenAPI | OpenAPI 3.1 / JSON Schema 2020-12
| String interpolation emits a minimal document; escaping, merged same-path verbs,
parameter conversion and schema components need independent validation/fixes.
| MaridRPC | JSON-RPC 2.0 / MCP and SSE hook
| In-process request/response dispatch. No MCP lifecycle/transport implementation;
no independent network-client proof. Internal error text includes raw exceptions.
| MaridGraphQL | SDL, standard introspection, then resolver runtime
| SDL emitter plus substring-based `__schema` response; other queries return empty
`data`. This is not a conformant executor or full introspection implementation.
| MaridTransport | HTTP/1.1, SSE, WS, chunks/trailers; later HTTP/2
| SSE/status-line and gRPC/gRPC-Web framing utilities. No HTTP.jl listener,
WebSocket server or production HTTP/2/gRPC transport.
| MaridCore | Local trie, immutable routing, context, middleware, lifecycle
| In-process routing/dispatch, contexts, error mapping and channels. Router internals
are mutable; root registration fails. Real listener/lifecycle and allocation claims
need evidence; a structural `struct` is not deep immutability.
| ArangoDB | Auth/pooling, documents/edges, cursors, AQL, transactions/retries
| Public operations use `_get_mock_db`; AQL is simulated and transaction functions
are stubs. A configured endpoint is not contacted by the current CRUD tests.
| MaridStorage | Memory, SQLite, DuckDB; optional Arango extension
| Memory engine and Arango-named adapter backed by `in_memory_fallback`.
No SQLite/DuckDB implementation or true optional Arango extension.
| MaridControl | Atomic snapshots, log, etcd/Consul, invalidation
| Atomic reference, shallow Dict snapshots, memory log/backend. No etcd/Consul
adapter. `swap_snapshot!` has a reproduced return-type failure; deep immutability
and multi-reader/multi-writer correctness need evaluation.
| MaridLive | HTMX/Turbo/Datastar over live transport
| String/header helpers with local tests, not real-browser/transport evidence.
Session/CSRF/OIDC/views/forms security gate remains open.
| MaridCRDT | LWW, OR-Set, counters, presence
| Small implementations and finite examples. No demonstrated partition/property
campaign sufficient for charter Phase 6 acceptance.
| MaridRaft | Conditional late consensus implementation
| In-process election/log simulation. Presence does not satisfy the charter's
etcd-insufficiency justification, durable distributed operation or approved Jepsen budget.
|===

== Implemented in this change

=== Native emitter and CLI

`packages/MaridIR/src/capability.jl` adds `emit_capability_spec` with no dependencies
or IR type changes. It emits gateway DSL v1 YAML, merges same-path verbs, normalizes
methods, escapes/anchors path patterns, translates colon parameters and terminal
wildcards, handles explicit exposure/capability annotations and deterministically
sorts output. Invalid/ambiguous routes, unsupported verbs, conflicting annotations,
empty policies and management endpoint collisions are rejected.

No implicit HEAD/OPTIONS, inferred role mappings or generated cryptographic tokens.
Methods without HTTP bindings are omitted. Global exposure has no silent default:

[source,bash]
----
./scripts/marid generate capability-spec fixtures/capability/service.jl \
  --global-verbs GET > policy.yaml
----

The new helper passes filenames as ARGS, works outside the repo cwd, executes only
explicit trusted descriptor input and keeps diagnostics off machine-readable stdout.
Existing unrelated generator stubs are documented, not silently represented as fixed.

=== Sidecar topology and documentation

Created the requested `docs/deployment/docker-compose.adoc` (it did not exist at
baseline), plus an included `compose.yaml`. The front-facing gateway mounts generated
policy read-only, targets `http://marid:8080`, publishes only loopback port 8088,
and shares a private backend network with an application that has no host ports.
Image digests are explicit prerequisites; no imaginary published image or executable
Marid server is claimed. The existing production guide links to this bounded recipe.

ADR-0007 records native v1, explicit globals, conservative overlap rejection,
annotation semantics, pure MaridIR and scope limits. The project brief is untouched.

=== Tests and future CI wiring

Added 55 emitter assertions, a golden fixture, CLI boundary tests and an Elixir
