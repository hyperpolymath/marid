= Marid acceptance evidence ledger
:toc:

Updated 2026-09-19. This ledger supersedes unqualified readiness assertions in
historical Gate 1/3/4/5 audits. The brief and charter requirements are unchanged.
CLADE's `incubating` phase remains authoritative; STATE is corrected to experimental.
No package, release or deployment is accepted solely because unit tests pass.

== Ordered checkpoint 1: evidence and CI repair

Implemented and evaluated before endpoint work:

* README, Arango README and STATE corrected; historical audits prominently marked
  superseded. Thirteen prototypes exist; persistence/protocol/browser acceptance
  remains unproven. No fabricated percentage is used to declare readiness.
* Julia 1.10.10 and Bun 1.4.2 local baselines pinned. AffineScript compilation is
  still a feasibility blocker; no unverified compiler version is invented.
* Missing top-level permissions on Julia/DCO workflows added; uncovered action
  refs replaced with immutable revisions already verified in the prior recon.
* Official `gh-actions-lock` v0.1.6 `--verify-local` now passes, as does the local
  pinning checker. Bare-SHA traceability warnings are retained. Remote re-resolution
  requires a GitHub token and was not performed; no lockfile was edited by hand.
* Required-file gate now accepts single-source compatibility symlinks at root
  for GOVERNANCE/MAINTAINERS and an architecture entry point under docs/. The
  allowlist documents why the aliases exist. No governance prose is duplicated.
* Exact pinned required-files checker executed locally with repository owner set;
  all presence/substance checks pass. Workflow SPDX/permissions check passes.
* Password example changed to environment lookup. It was demonstration text,
  not a verified leaked credential. Fixed-template innerHTML parsing replaced
  with DOM construction; it was not shown to accept attacker HTML. No security
  scanner rule was disabled or finding blanket-suppressed.
* Existing Bun shim/unit tests pass; this is not real-browser acceptance.

External limitations, not green results:

* Hosted checks cannot be rerun until an authorized push/PR.
* CodeQL startup failure still needs GitHub check/configuration diagnostics.
* Pages requires owner verification/enabling of the Pages Actions site; no account
  settings were changed. Sonar's exit-1 cause needs scanner logs/project/token
  verification; no claim is made that automatic analysis is configured.
* Full remote action re-resolution and estate Hypatia rerun were not executed.
  Offline coverage and local source corrections do not replace them.

== Subsequent checkpoints

Checkpoint 2 (IR-driven HTTP/JSON) and checkpoint 3 (strict gateway) must append

== Ordered checkpoint 2: real IR-driven HTTP/JSON

Implemented after checkpoint 1: JSON3 encoding/decoding and q-value/specificity
negotiation; HTTP.jl bounded unary listener; optional MaridCore Codec/Transport
extension; all-or-nothing IR method binding; root and nested-parameter routing
fixes; explicit lifecycle flags and sanitized 500 responses. New example at
`examples/http_json` uses one descriptor for routes and policy generation.

Executed with Julia 1.10.10: `scripts/bootstrap.jl examples/http_json`, then
`examples/http_json/test/runtests.jl`: *38 assertions passed* across real HTTP
sockets, curl and a raw chunked request. Includes 400/404/405/406/413/415/500/503/504
behavior, Unicode/quote JSON round trip, q=0, mutation-count protection, root and
nested paths, shutdown, and application error redaction. Thirteen independent
package suites also pass after bootstrapping; Codec adds twelve wire/negotiation
assertions. These are not ArangoDB, real-browser or arbitrary-stream tests.

CI now instantiates local package dependencies explicitly and contains a separate
real-HTTP job. Hosted execution is unverified. See the example README for precise
resource/lifecycle limits; no full production transport acceptance is asserted.

== Ordered checkpoint 3: strict gateway and actual network path

Implemented after the real HTTP checkpoint, in *both* repositories, locally only.
Marid retains explicit legacy globals and adds opt-in `--deny-by-default` /
`gateway_profile=:strict`. Strict policy is native DSL v1 with empty globals;
unpatched upstream rejects it. `test/interop/gateway-strict.patch` records the
paired changes against gateway `19b343c1e9b7c61668c60887369783d12a486f41`.

The gateway now distinguishes unmatched paths from matched paths with forbidden
verbs. Exact path precedence and ambiguous-regex denial are tested; retired main
handles cannot use a new regex companion. Invalid exposure strings/non-string
verbs reject. Body limits, raw JSON bytes, repeated response header values, no
redirect following and no automatic retries are covered. Two pre-existing plugin
syntax errors, policy-load logging of `:ok`, and missing application-lifetime ETS
initialization were necessary compile/startup repairs. Plugin security behavior
has not been validated by those syntax repairs.

Executed with Julia 1.10.10, Bun 1.4.2, Elixir 1.19.4 / OTP 27:

* All thirteen package suites rerun after the changes: *385 assertions pass*
  (prototype tests do not prove persistence). MaridIR accounts for 79; strict/legacy
  CLI goldens pass. Direct HTTP/JSON tests remain 38/38.
* `elixir test/interop/capability_gateway.exs <patched-gateway>`: native loader,
  validator, compiler and lookup pass, including explicit legacy unknown-path
  fallback and strict denial. This test alone is not a proxy test.
* Eight targeted gateway files: *6 properties + 66 tests, zero failures*. Includes
  31 compiler/validator/strict tests and four real-upstream wire tests.
* `bash test/interop/run_http_gateway.sh <patched-gateway>`: *7 tests / 47 Bun
  assertions pass*. Full application starts from generated IR policy; real HTTP
  goes through Cowboy/Req to Julia HTTP.jl/Core/JSON3. Allowed echo bytes roundtrip;
  missing verbs and unknown/near-miss paths deny; forged internal trust stays
  untrusted; 400/406/413/415 are preserved; only the valid echo increments its
  in-memory mutation count. Stopping the backend yields 502; policy denial still
  works without it. Synthetic internal probe contains no actual private data.
* `mix test --seed 1` on patched gateway: *12 properties, 263 tests, 15 failures*.
  Baseline with only the two required plugin compile repairs: *12 properties,
  253 tests, 19 failures*. All 15 patched failure names reproduce on that baseline
  at the same seed. They are NOT waived or hidden as a green full-suite result.
  Failures include malformed fuzz-property declarations, a Plug Host-header test,
  management-route/stealth expectations and shared audit-buffer test state.
  Audit-path tests separately pass (2/2); persistent auditing is still unaccepted.

CI now applies the paired patch to an immutable gateway checkout, runs native
policy plus targeted regression/wire tests, and starts the actual network runner.
It explicitly does not claim a green full gateway suite. Hosted CI remains unrun.
The authoritative local logs and baseline comparison accompany the delivery.

Remaining blockers:

* Existing dependency advisory output flags Cowboy 2.17.0, Cowlib 2.18.0 and Mint
  1.9.3; no upgrade/revalidation or vulnerability waiver was performed.
* Inactive plugins reference unsupported `Plug.Conn.get_private/2` and
  `:inet.parse_cidr_address/1`. Do not enable them as validated security controls.
* No container engine, production image build, TLS/mTLS acceptance, external
  management isolation, backend bypass proof, rollout/rollback or resource baseline.
* Main/regex association is corrected, but lifecycle/reload concurrency and dynamic
  table atom lifetime are not production-proven. Proxy response buffering is not
  streaming or a heap quota; general cancellation remains a release blocker.
* Real DB/transactions, durable audit, browser and protocol acceptance are still
  behind the ordered checkpoint review. Charter acceptance requirements are unchanged.
