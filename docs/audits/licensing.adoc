== Clean-Room Reimplementation Discipline

* **Genie.jl Attribution**: Marid.jl is inspired by Genie.jl (MIT licensed by Essenciary / Adrian Salceanu). Marid maintains a strict **clean-room boundary**:
  1. No code or test fixtures are copied or adapted from Genie.jl.
  2. No Genie-specific internal APIs or proprietary macro conventions are cloned.
  3. Marid differentiates itself fundamentally: an immutable Intermediate Representation (`MaridIR`), pure trie routing separated from transport, streaming symmetric handlers, and first-class native protocol adapters.
  4. Notice of inspiration is formally recorded in `THIRD_PARTY_NOTICES.md` and the framework charter.

== Policies for IDL and Generated Code

1. **Intermediate Representation (`MaridIR`)**:
   - The IR definition in `packages/MaridIR/` is original code licensed under MPL-2.0.
2. **Generated Schemas (`contracts/`)**:
   - Schema files generated by Marid tools (OpenAPI 3.1 JSON, GraphQL SDL, `.proto`, `.capnp`, `.bop`) from user-defined `MaridIR` services carry the user's license. The generator templates themselves are MPL-2.0.
3. **Generated Browser Clients**:
   - Code emitted by `MaridOpenAPI` or `MaridGraphQL` for browser consumption is treated as user code. Marid claims no copyright over the generated output.

== Contribution Hygiene & Governance

* **Developer Certificate of Origin (DCO)**:
  - Contributions are accepted under the DCO (Signed-off-by convention), explicitly rejecting corporate Contributor License Agreements (CLAs).
  - A DCO validation workflow (`.github/workflows/dco.yml`) is scheduled to enforce commit sign-offs.
* **SPDX Headers**:
  - Every single source file, documentation document, script, and manifest carries explicit SPDX license and copyright identifier headers.
