== Multi-Protocol Service Surface Verification

The reference application verifies that the identical Julia business logic (`TaxonService`)
serves all communication protocols without divergence:

1. **HTTP / REST**:
   * `GET /api/v1/taxa`: Lists all taxa.
   * `GET /api/v1/taxa/:id`: Returns individual taxon with 404 Problem Details on missing IDs.
   * `GET /api/v1/neighborhood/:id`: Traverses graph edges up to requested depth.
   * `POST /api/v1/analysis`: Executes character matrix distance calculations and streams progress frames.
2. **GraphQL SDL**:
   * Canonical schema emission exposing `Taxon` type and `listTaxa`, `getTaxon` query operations.
3. **Binary Serialization Fixtures**:
   * Bebop schema (`fixtures/schema.bop`) and Cap'n Proto schema (`fixtures/schema.capnp`) fixtures with documented semantics.
4. **Reactive Events**:
   * Server-Sent Events (SSE) streaming with RFC-compliant framing and sequence tracking.
