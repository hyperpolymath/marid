= MaridGRPC.jl — native-protocol gRPC (planned)

Native-protocol unary calls and server streaming: metadata, deadlines,
cancellation, status/trailers (`PROJECT_BRIEF.md` §2).

Ready when: an independent standard gRPC client successfully exercises these
features. The supported streaming modes must be identified exactly; anything
else is explicitly unsupported.

Status: Gate 0 skeleton. `Project.toml`, `src/`, and `test/` land at Gate 2.
HTTP/2 and gRPC feasibility is audited at Gate 0, and the highest-risk
assumptions are proved with disposable spikes at Gate 1.
