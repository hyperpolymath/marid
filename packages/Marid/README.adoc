= Marid.jl — core (planned)

Small core that assembles the integrations without making every integration
mandatory (`PROJECT_BRIEF.md` §2–§3).

Initial scope: local routing, middleware, lifecycle, application context,
contract bindings, HTTP/JSON, live-update integration.

Ready when: the reference application (`examples/relationship_explorer/`)
uses the integrations without duplicating business logic.

Status: Gate 0 skeleton. `Project.toml`, `src/`, and `test/` land at Gate 2.
