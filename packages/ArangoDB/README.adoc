= ArangoDB.jl — native ArangoDB client (planned)

HTTP-based ArangoDB client in its own package: authentication,
connection pooling, cursors, bound AQL queries, transactions, retries,
and changefeeds (`docs/MARID-FRAMEWORK.adoc`, storage set).

Status: Gate 0 skeleton. Implemented at Phase 3 against a real ArangoDB
container (brief §9).
