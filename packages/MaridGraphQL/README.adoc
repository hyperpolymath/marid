= MaridGraphQL.jl — GraphQL execution (planned)

Queries and mutations: schema validation, variables, resolver context,
partial errors, batching hooks, resource limits (`PROJECT_BRIEF.md` §2).

Ready when: standard GraphQL clients work, and authorization, malformed
queries, limits, and partial failures are tested. Subscriptions require a
separately identified transport implementation.

Status: Gate 0 skeleton. `Project.toml`, `src/`, and `test/` land at Gate 2.
GraphQL execution support (not just schema parsing) is audited at Gate 0.
