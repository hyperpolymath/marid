= MaridGraphQL.jl — GraphQL SDL and runtime (planned)

IR → GraphQL SDL plus introspection first; the resolver runtime
(queries, mutations, validation, variables, resolver context, partial
errors, batching hooks, resource limits) follows, over MaridIR
(`docs/MARID-FRAMEWORK.adoc`, launch set). Subscriptions ride SSE,
then WebSocket.

Status: Gate 0 skeleton. Implemented at Phase 1 (brief §9).
