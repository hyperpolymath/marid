= MaridControl.jl — Distributed Control Plane & Atomic Swap Engine
:toc:
:sectnums:

Distributed control plane, atomic snapshot configuration swaps, sequential append-only logs,
and changefeed invalidation for Marid (`PROJECT_BRIEF.md` §2 Phase 4; `docs/MARID-FRAMEWORK.adoc`).

Consensus, configuration, and schema live here — **never on the request path**.
Nodes serve traffic with the control plane completely offline or disconnected.

Status: **Implemented & Verified (Phase 4)**.

== Public API

* `Snapshot(version, timestamp, data)`: Immutable versioned state container.
* `AtomicConfig(initial_snapshot)`: Lock-free atomic reference container.
* `get_snapshot(cfg)`: Zero-lock, allocation-free snapshot retrieval on the request path.
* `swap_snapshot!(cfg, next_snapshot)`: Atomic pointer exchange.
* `update_snapshot!(cfg, mutator_fn)` / `update_snapshot!(mutator_fn, cfg)`: Compare-and-swap retry loop.
* `LogEntry(index, term, key, value, timestamp)`: Sequential log record.
* `SequentialLog()`: Thread-safe append-only sequence log.
* `append_log!(log, term, key, value)` & `read_log_from(log, start_index)`.
* `ControlBackend`: Seam for consensus storage (`InMemoryControlBackend`, etcd/Consul).
* `ControlNode(backend)`: Node coordinator.
* `serve_request(node, key)`: Request serving from local snapshot (guaranteed control-plane-down isolation).
* `sync_from_backend!(node, updates)`: Asynchronous control plane state synchronization.

== Feature Matrix

[cols="1,1,2",options="header"]
|===
| Feature | Status | Verification Evidence

| Atomic Pointer Swaps | Supported | Multi-threaded concurrent reader/writer race stress test passed with 0 corruptions.
| Control-Plane-Down Serving | Supported | Node serves 100% of read requests cleanly when backend connection is severed.
| Sequential Log Playback | Supported | Append and ordered slicing verified.
| Changefeed Invalidation | Supported | Event propagation across subscriber channels.
|===

== Unsupported Features
* Request-time consensus barriers or distributed locking on read paths (prohibited by design).
* Arbitrary mutable shared memory across worker tasks without atomic containers.

== Runnable Example

[source,julia]
----
using MaridControl

# 1. Initialize control node with backend
backend = InMemoryControlBackend()
node = ControlNode(backend)

# 2. Push initial routing configuration
sync_from_backend!(node, Dict{String, Any}("rate_limit" => 500, "active_routes" => ["/taxa", "/analysis"]))

# 3. Serve request with 0 control-plane contention
limit = serve_request(node, "rate_limit") # 500

# 4. Sever backend connection (simulating network partition)
set_connected!(backend, false)

# 5. Node continues serving normally
@assert serve_request(node, "rate_limit") == 500
----
