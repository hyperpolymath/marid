= relationship_explorer — reference application (planned)

The Marid reference application: a small ArangoDB-backed relationship
explorer and the program's integration test (`PROJECT_BRIEF.md` §7).

It must support creating and retrieving entities, connecting entities with
edges, exploring a bounded neighborhood, and running a small Julia analysis
with progress updates — exposed as the same application services through
HTTP/JSON and GraphQL, plus gRPC once Phase 8 lands, with Cap'n Proto and
Bebop import/export fixtures of explicitly documented semantics.

Frontends: AffineScript (JaffaScript face), React, and Vue, plus one small
shared Web Component such as a progress indicator.

This application exercises the integrations; it must not reimplement
business logic per protocol.

Status: Gate 0 skeleton. Built at Gate 4.
