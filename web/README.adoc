= web — browser client

Framework-independent browser client with thin framework integrations
(`PROJECT_BRIEF.md` §5).

[cols="1,3"]
|===
| Directory | Package and purpose

| `client/` | `@marid/client` — framework-independent client: cancellation,
errors, live subscriptions, reconnect/resynchronization.
| `react/` | `@marid/react` — thin React integration and lifecycle cleanup.
| `vue/` | `@marid/vue` — thin Vue integration and lifecycle cleanup.
| `elements/` | `@marid/elements` — small portable Web Components
demonstrator; not a new comprehensive widget library.
|===

The client exposes promises, `AbortSignal`, async iterables where useful,
and snapshot/subscription interfaces for reactive state. Existing GraphQL
and generated API clients must also work directly — nothing forces every
client through a universal Marid SDK.

Status: Gate 0 skeleton. Packages are implemented at Gate 4 against the
browser-event contract written at Gate 2.
